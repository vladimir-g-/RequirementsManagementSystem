# BRL-0011 — Идентификация проекта

## Правило

Название и код проекта обязательны. Название проекта содержит не более 200 символов, может включать любые печатные символы и уникально без учёта регистра. Код проекта уникален без учёта регистра, задаётся при создании проекта и может быть изменён только пока проект не содержит ни требований, ни групп. Название проекта может быть изменено независимо от наличия в проекте требований и групп.

Код проекта используется при формировании номеров требований, если для пары «проект — тип» не настроен префикс, поэтому к коду применяется формат префикса номера требования, установленный в [BRL-0004](./BRL-0004.md).

## Обоснование

Правило обеспечивает однозначную идентификацию проектов и стабильность нумерации требований: код проекта нельзя изменить после появления в проекте требований или групп.
