# BRL-0013 — Удаление неиспользуемого типа требования

## Правило

Тип требования может быть удалён только если он не используется ни одним требованием ни в одном проекте. При удалении типа требования система удаляет также настройки префиксов номеров требований для всех пар «проект — тип», содержащих этот тип. Сами требования, проекты и настройки префиксов для других типов при этом не изменяются.

## Обоснование

Правило предотвращает нарушение целостности данных справочных значений требований ([BRL-0005](./BRL-0005.md)) и оставляет без содержания настройки нумерации. Удаление настроек префиксов согласовано с [BRL-0012](./BRL-0012.md): настройки префиксов для пары «проект — тип» не должны существовать для удалённого типа.
