# BRL-0002 — Доступ и права в пределах проекта

## Правило

Пользователь без роли администратора может иметь доступ только к назначенным ему проектам. В рамках назначенного проекта права `create` (создание), `read` (чтение), `update` (изменение) и `delete` (удаление) назначаются независимо друг от друга; права `update` и `delete` сами по себе не предоставляют `read`. Для выбора требования пользователь должен иметь `read`. Для изменения требования достаточно права `update`, для удаления — права `delete`; право `read` дополнительно для этих операций не требуется. Без `read` пользователь не может просматривать требования или группы проекта.

Создание и удаление связи требования трактуются как изменение требования: для этих операций достаточно права `update`, а право `read` требуется для открытия карточки требования и для выбора требования, с которым устанавливается связь. Право `delete` относится к удалению самого требования и на связи не распространяется.

Пользователь может быть создан без назначенных проектов; в этом случае он не имеет доступа к требованиям и группам, а проекты и права могут быть назначены ему позднее.

## Обоснование

Это правило фиксирует назначение проектов и разграничение доступа по операциям, предусмотренные в MVP.
