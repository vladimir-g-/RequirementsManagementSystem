# BRL-0007 — Общий каталог типов связей

## Правило

Система использует единый каталог типов связей для всех проектов. Форму каталога и возможность просматривать или изменять его имеет только пользователь с существующей системной ролью «Администратор». Администратор может создавать, изменять и удалять типы. Изменение направленности применяется ко всем существующим связям этого типа. Удаление типа удаляет все связи этого типа во всех проектах, не удаляя связанные требования.

## Обоснование

Типы связей и правила их администрирования должны быть единообразны для проектов.
