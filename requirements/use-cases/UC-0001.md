# UC-0001 — Вход в систему

## Цель

Получить доступ к защищённым функциям системы после аутентификации.

## Основной актор

Пользователь

## Триггер

Пользователь инициирует вход в систему.

## Предварительные условия

- У пользователя есть учётная запись.
- Пользователь не аутентифицирован.

## Основной сценарий

1. Пользователь вводит логин и пароль.
2. Система аутентифицирует пользователя и предоставляет ему доступ к разрешённым функциям.

## Исключительные сценарии

- Если учётные данные не подтверждены, система не предоставляет доступ к защищённым функциям.
