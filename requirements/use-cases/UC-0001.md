# UC-0001 — Вход в систему

## Цель

Получить доступ к защищённым функциям системы после успешной аутентификации.

## Основной исполнитель

Пользователь

## Дополнительные исполнители

- Нет

## Триггер

Пользователь инициирует вход в систему.

## Предварительные условия

- Пользователь не аутентифицирован в текущем сеансе.

## Основной поток

1. Пользователь вводит логин и пароль.
2. Система проверяет учётные данные: если они подтверждены, поток продолжается с шага 3; иначе выполняется исключительный поток E1.
3. Система создаёт сеанс пользователя и предоставляет доступ к разрешённым функциям.
4. Система отображает интерфейс, доступный после входа.

## Альтернативные потоки

- Нет

## Исключительные потоки

### E1 — Учётные данные не подтверждены

1. Система отклоняет вход и не создаёт сеанс.

## Состояние после выполнения

- При успешном выполнении пользователь аутентифицирован и имеет доступ только к проектам и функциям, разрешённым его правами.
- При выполнении E1 пользователь не аутентифицирован.
