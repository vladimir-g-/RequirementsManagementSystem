# UC-0001 — Вход в систему

## Цель

Получить доступ к защищённым функциям системы после аутентификации.

## Основной актор

Пользователь

## Триггер

Пользователь инициирует вход в систему.

## Предварительные условия

- У пользователя есть учётная запись.
- Пользователь не аутентифицирован.

## Основной сценарий

1. Пользователь вводит логин и пароль.
2. Если система подтверждает учётные данные, она аутентифицирует пользователя и предоставляет ему доступ к разрешённым функциям; если система не подтверждает учётные данные, выполняется исключительный сценарий E1.

## Исключительные сценарии

### E1 — Учётные данные не подтверждены

1. Этот сценарий выполняется, если на шаге 2 основного сценария система не подтвердила введённые учётные данные.
2. Система не предоставляет доступ к защищённым функциям.
