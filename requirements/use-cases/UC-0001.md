# UC-0001 — Вход в систему

## Goal

Получить доступ к защищённым функциям системы после успешной аутентификации.

## Primary actor

Пользователь

## Supporting actors

- Система проверки учётных данных
- Система управления доступом

## Trigger

Пользователь инициирует вход в систему через форму аутентификации.

## Preconditions

- У пользователя есть действующая учётная запись.
- Пользователь не аутентифицирован в текущем сеансе.

## Main flow

1. Пользователь вводит логин и пароль.
2. Система проверяет корректность введённых данных.
3. Если учётные данные подтверждены, система создаёт сеанс пользователя и предоставляет доступ к разрешённым функциям.
4. Система отображает интерфейс, доступный после входа в систему.
5. Если система подтверждает учётные данные, она аутентифицирует пользователя и предоставляет ему доступ к разрешённым функциям; если система не подтверждает учётные данные, выполняется исключительный сценарий E1.

## Exception flows

### E1 — Неактивная или несуществующая учётная запись

1. Пользователь пытается войти под учётной записью, которая не существует, отключена или заблокирована.
2. Система не создаёт сеанс и отображает сообщение о невозможности входа.
