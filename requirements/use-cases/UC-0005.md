# UC-0005 — Настройка нумерации требований

## Goal

Настроить префикс нумерации новых требований для конкретного проекта и типа требования.

## Primary actor

Администратор

## Supporting actors

- Система настройки проекта
- Система формирования номеров требований

## Trigger

Администратор открывает настройки нумерации проекта или инициирует изменение префикса.

## Preconditions

- Администратор аутентифицирован.
- Пользователь имеет доступ к проекту и правам администрирования нумерации.

## Main flow

1. Администратор выбирает проект и тип требования.
2. Администратор вводит префикс для выбранной пары «проект — тип».
3. Система проверяет корректность префикса.
4. Система сохраняет префикс и применяет его к дальнейшей нумерации требований этого типа в проекте.

## Alternative flows

### A1 — Изменение существующего префикса

1. Администратор выбирает ранее настроенную пару «проект — тип».
2. Администратор редактирует префикс и сохраняет изменения.
3. Система обновляет правило нумерации для последующих требований.

### A2 — Отмена действия

1. Администратор отменяет редактирование настроек.
2. Система сохраняет текущее состояние без изменения префикса.

## Exception flows

### E1 — Некорректный префикс

1. Администратор вводит значение, которое не соответствует требованиям формата префикса.
2. Система отклоняет сохранение и показывает причину ошибки.
