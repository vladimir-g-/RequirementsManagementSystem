# UC-0005 — Настройка нумерации требований

## Цель

Настроить нумерацию новых требований по проекту и типу.

## Основной актор

Администратор

## Триггер

Администратор настраивает префикс нумерации требований для проекта и типа требования.

## Предварительные условия

- Администратор аутентифицирован.

## Основной сценарий

1. Администратор выбирает проект и тип требования.
2. Администратор вводит префикс.
3. Система проверяет префикс: если он соответствует требованиям, система сохраняет его для выбранной пары «проект — тип»; иначе выполняется исключительный сценарий E1.
4. Если префикс сохранён, при создании требования этого типа в данном проекте система использует настроенный префикс.

## Исключительные сценарии

### E1 — Префикс пуст, длиннее 20 символов, содержит недопустимые символы или уже используется для этой пары

1. Этот сценарий выполняется, если на шаге 3 основного сценария система обнаружила, что префикс пуст, превышает 20 символов, содержит символы помимо букв, цифр, `_` и `-` либо уже используется для выбранной пары «проект — тип».
2. Система отклоняет префикс.
