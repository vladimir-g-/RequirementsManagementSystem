# UC-0005 — Настройка нумерации требований

## Цель

Настроить префикс номеров требований для пары «проект — тип требования».

## Основной исполнитель

Администратор

## Дополнительные исполнители

- Нет

## Триггер

Администратор инициирует настройку префикса для проекта и типа требования.

## Предварительные условия

- Администратор аутентифицирован.
- Проект и тип требования существуют.

## Основной поток

1. Администратор выбирает проект и тип требования.
2. Администратор вводит префикс и сохраняет настройку.
3. Система проверяет, что префикс непустой, не длиннее 20 символов, содержит только буквы, цифры, `_` или `-` и уникален для выбранной пары «проект — тип»: если проверки пройдены, поток продолжается с шага 4; иначе выполняется исключительный поток E1.
4. Система сохраняет префикс.
5. При последующем создании требования выбранного типа в этом проекте система использует сохранённый префикс.

## Альтернативные потоки

- Нет

## Исключительные потоки

### E1 — Некорректный или занятый префикс

1. Система отклоняет настройку и не сохраняет новый префикс.

## Состояние после выполнения

- При успешном выполнении префикс сохранён для выбранной пары «проект — тип» и используется при формировании номеров новых требований.
- При выполнении E1 настройка не изменена.
