# UC-0005 — Настройка нумерации требований

## Goal

Настроить префикс нумерации новых требований для конкретного проекта и типа требования.

## Primary actor

Администратор

## Триггер

Администратор настраивает префикс нумерации требований для проекта и типа требования.

## Предварительные условия

- Администратор аутентифицирован.
- Администратор имеет системную роль «Администратор».

## Main flow

1. Администратор выбирает проект и тип требования.
2. Если для выбранной пары «проект — тип» уже задан префикс и администратор хочет его изменить, выполняется альтернативный сценарий A1; если администратор задаёт префикс впервые, он вводит его и переходит к шагу 3; если администратор отменяет редактирование, выполняется альтернативный сценарий A2.
3. Система проверяет, что префикс непустой, содержит не более 20 символов, состоит только из букв, цифр, `_` или `-` и уникален в рамках выбранной пары «проект — тип»; если проверка не пройдена, выполняется исключительный сценарий E1.
4. Система сохраняет допустимый префикс для выбранной пары «проект — тип».
5. При создании требования этого типа в данном проекте система использует настроенный префикс.

## Alternative flows

### A1 — Изменение существующего префикса

1. Администратор вводит новый префикс и продолжает основной сценарий с шага 3.

### A2 — Отмена действия

1. Система сохраняет текущее состояние без изменения префикса.

## Exception flows

### E1 — Префикс не соответствует формату

1. Система отклоняет сохранение префикса и сообщает причину ошибки.
