# UC-0009 — Удаление связи между требованиями

## Цель

Удалить существующую связь между двумя требованиями, не удаляя сами требования.

## Основной актор

Пользователь

## Триггер

Пользователь открывает карточку требования, чтобы удалить одну из его связей.

## Предварительные условия

- Пользователь аутентифицирован.
- Выбран активный проект.
- Между требованиями существует связь.

## Основной сценарий

1. Система проверяет право `read` пользователя в активном проекте; если права нет, выполняется исключительный сценарий E1.
2. Пользователь открывает карточку одного из связанных требований и выбирает существующую связь для удаления.
3. Система проверяет право `update`; если права нет, выполняется исключительный сценарий E1.
4. Система удаляет связь с карточек обоих требований, не удаляя сами требования.

## Исключительные сценарии

### E1 — Недостаточно прав

1. Система отказывает в доступе к карточке или отклоняет удаление связи в соответствии с недостающим правом.
