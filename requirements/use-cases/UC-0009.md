# UC-0009 — Удаление связи между требованиями

## Цель

Удалить существующую связь между двумя требованиями, не удаляя сами требования.

## Основной актор

Пользователь

## Триггер

Пользователь открывает карточку требования, чтобы удалить одну из его связей.

## Предварительные условия

- Пользователь аутентифицирован.
- Выбран активный проект.
- Между требованиями существует связь.
- Для успешного удаления связи пользователь имеет права `read` и `update` в активном проекте; отсутствие необходимого права обрабатывается в исключительном сценарии E1.

## Основной сценарий

1. Пользователь открывает карточку одного из связанных требований.
2. Пользователь выбирает существующую связь и инициирует её удаление.
3. Система удаляет связь с карточек обоих требований, не удаляя сами требования.

## Исключительные сценарии

### E1 — Недостаточно прав

1. Этот сценарий выполняется, если пользователь без права `read` пытается открыть карточку требования либо пользователь без права `update` пытается удалить связь.
2. Система отказывает в доступе к карточке или отклоняет удаление связи в соответствии с недостающим правом.
