# UC-0007 — Настройка типов связей требований

## Цель

Управлять общим каталогом типов связей требований.

## Основной актор

Администратор

## Триггер

Администратор выбирает пункт «Типы связей» в меню «Администрирование».

## Предварительные условия

- Администратор аутентифицирован.
- Администратор имеет системную роль «Администратор».

## Основной сценарий

1. Система отображает общий каталог типов связей, используемый во всех проектах.
2. Администратор создаёт тип связи, задавая его название и направленность.
3. Система сохраняет тип в общем каталоге для всех проектов.

## Альтернативные сценарии

### A1 — Изменение направленности типа

1. Этот сценарий выполняется, если администратор выбирает существующий тип и изменяет его направленность.
2. Система сохраняет новую направленность и применяет её ко всем существующим связям этого типа во всех проектах.

### A2 — Переименование типа

1. Этот сценарий выполняется, если администратор выбирает существующий тип и изменяет его название.
2. Система сохраняет новое название типа в общем каталоге для всех проектов.

### A3 — Удаление типа

1. Этот сценарий выполняется, если администратор выбирает существующий тип и подтверждает его удаление.
2. Система удаляет тип и все связи этого типа во всех проектах, не удаляя связанные требования.
