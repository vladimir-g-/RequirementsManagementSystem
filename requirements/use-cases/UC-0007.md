# UC-0007 — Настройка типов связей требований

## Цель

Управлять общим каталогом типов связей требований.

## Основной актор

Администратор

## Триггер

Администратор выбирает пункт «Типы связей» в меню «Администрирование».

## Предварительные условия

- Администратор аутентифицирован.
- Администратор имеет системную роль «Администратор».

## Основной сценарий

1. Система отображает общий каталог типов связей, используемый во всех проектах.
2. Администратор выбирает операцию: если он создаёт тип связи и задаёт название и направленность, система переходит к шагу 3; если он изменяет направленность существующего типа, выполняется альтернативный сценарий A1; если он переименовывает существующий тип, выполняется альтернативный сценарий A2; если он подтверждает удаление типа, выполняется альтернативный сценарий A3.
3. Система сохраняет тип в общем каталоге для всех проектов.

## Альтернативные сценарии

### A1 — Изменение направленности типа

1. Система сохраняет новую направленность и применяет её ко всем существующим связям этого типа во всех проектах.

### A2 — Переименование типа

1. Система сохраняет новое название типа в общем каталоге для всех проектов.

### A3 — Удаление типа

1. Система удаляет тип и все связи этого типа во всех проектах, не удаляя связанные требования.
