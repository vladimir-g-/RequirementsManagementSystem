# UC-0012 — Удаление требования

## Цель

Удалить требование из активного проекта и связанные с ним связи.

## Основной актор

Пользователь

## Триггер

Пользователь инициирует удаление требования в активном проекте.

## Предварительные условия

- Пользователь аутентифицирован.
- Выбран активный проект.
- Требование принадлежит активному проекту.
- Пользователь имеет право `delete` (удаление) в активном проекте.

## Основной сценарий

1. Пользователь выбирает требование и инициирует его удаление.
2. Система запрашивает подтверждение удаления.
3. Пользователь подтверждает удаление.
4. Система удаляет требование и все его связи, не удаляя связанные требования.
5. Система сообщает об успешном удалении требования.

## Альтернативные сценарии

### A1 — Пользователь отменяет удаление

1. Этот сценарий выполняется, если пользователь отменяет действие или не подтверждает удаление на шаге 3.
2. Система не удаляет требование и его связи.

## Исключительные сценарии

### E1 — Недостаточно прав

1. Этот сценарий выполняется, если пользователь без права `delete` пытается удалить требование.
2. Система отклоняет удаление и сохраняет требование и его связи без изменений.
