# UC-0012 — Удаление требования

## Цель

Удалить требование из активного проекта и связанные с ним связи.

## Основной актор

Пользователь

## Триггер

Пользователь инициирует удаление требования в активном проекте.

## Предварительные условия

- Пользователь аутентифицирован.
- Выбран активный проект.
- Требование принадлежит активному проекту.

## Основной сценарий

1. Пользователь инициирует удаление требования; если у него нет права `delete` в активном проекте, выполняется исключительный сценарий E1.
2. Пользователь выбирает требование для удаления. Способ выбора при отсутствии права `read` не определён ([OQ-0006](../questions/OQ-0006.md)).
3. Система запрашивает подтверждение удаления.
4. Если пользователь подтверждает удаление, система удаляет требование и все его связи, не удаляя связанные требования; если пользователь отменяет действие или не подтверждает его, выполняется альтернативный сценарий A1.
5. Если требование было удалено на шаге 4, система сообщает об успешном удалении; если пользователь отменил действие, основной сценарий завершается через A1 без сообщения об успешном удалении.

## Альтернативные сценарии

### A1 — Пользователь отменяет удаление

1. Система не удаляет требование и его связи.

## Исключительные сценарии

### E1 — Недостаточно прав

1. Система отклоняет удаление и сохраняет требование и его связи без изменений.
