# UC-0006 — Выход из системы

## Цель

Завершить текущий сеанс пользователя и прекратить доступ к защищённым функциям до повторного входа.

## Основной исполнитель

Пользователь

## Дополнительные исполнители

- Нет

## Триггер

Пользователь инициирует выход из системы.

## Предварительные условия

- Пользователь аутентифицирован в текущем сеансе.

## Основной поток

1. Пользователь выбирает команду выхода из системы.
2. Система завершает текущий сеанс пользователя.
3. При последующем обращении к защищённой функции система не предоставляет доступ без действительной аутентификации.

## Альтернативные потоки

- Нет

## Исключительные потоки

- Нет

## Состояние после выполнения

- Пользователь больше не аутентифицирован и не имеет доступа к защищённым функциям системы.
