# UC-0006 — Выход из системы

## Goal

Завершить текущий сеанс пользователя и запретить дальнейший доступ к защищённым функциям до повторного входа.

## Primary actor

Пользователь

## Supporting actors

- Система управления сеансами
- Система защиты доступа

## Trigger

Пользователь инициирует выход из системы.

## Preconditions

- Пользователь аутентифицирован в текущем сеансе.

## Main flow

1. Пользователь выбирает команду выхода из системы.
2. Система завершает текущий сеанс пользователя.
3. Система очищает доступ к защищённым функциям и возвращает пользователя на страницу входа.

## Alternative flows

### A1 — Выход при уже неактивном сеансе

1. Пользователь инициирует выход после истечения срока действия текущего сеанса.
2. Система корректно завершает сеанс и не возвращает ошибку в пользовательский интерфейс.

## Exception flows

### E1 — Ошибка завершения сессии

1. В процессе выхода система не может корректно удалить текущий сеанс.
2. Система сообщает пользователю о проблеме и выполняет повторную попытку очистки состояния, если это предусмотрено архитектурой.
