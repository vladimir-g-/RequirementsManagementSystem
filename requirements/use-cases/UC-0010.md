# UC-0010 — Создание требования

## Цель

Добавить новое требование в активный проект.

## Основной актор

Пользователь

## Триггер

Пользователь инициирует создание требования в активном проекте.

## Предварительные условия

- Пользователь аутентифицирован.
- Выбран активный проект.
- Пользователь имеет право `create` (создание) в активном проекте.

## Основной сценарий

1. Пользователь инициирует создание требования.
2. Система предлагает указать обязательные и необязательные данные требования.
3. Пользователь вводит краткое описание, тип, важность и статус, а при необходимости подробное описание, сложность, релиз и группу.
4. Система проверяет введённые данные; если значения допустимы, система сохраняет требование и назначает ему номер согласно правилам нумерации проекта.
5. Система сообщает об успешном создании требования.

## Альтернативные сценарии

### A1 — Пользователь отменяет создание

1. Этот сценарий выполняется, если пользователь отменяет создание до сохранения требования.
2. Система не создаёт требование и сохраняет данные проекта без изменений.

## Исключительные сценарии

### E1 — Недопустимые данные требования

1. Этот сценарий выполняется, если при проверке на шаге 4 система обнаруживает недопустимое значение или группу, не принадлежащую активному проекту.
2. Система отклоняет создание требования и сообщает о причине.

### E2 — Недостаточно прав

1. Этот сценарий выполняется, если пользователь без права `create` инициирует создание или сохранение требования.
2. Система отказывает в создании требования и сохраняет данные проекта без изменений.
