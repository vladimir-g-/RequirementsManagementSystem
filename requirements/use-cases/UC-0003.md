# UC-0003 — Организация требований по группам

## Goal

Организовать требования проекта в иерархическую структуру групп и обеспечить корректное отображение требований по выбранной группе.

## Primary actor

Пользователь

## Supporting actors

- Система структуры требований
- Система проверки иерархии групп

## Trigger

Пользователь создаёт, изменяет или удаляет группу требований в проекте.

## Preconditions

- Пользователь аутентифицирован и имеет доступ к проекту.
- У пользователя есть права на изменение структуры групп.

## Main flow

1. Пользователь создаёт группу и при необходимости назначает ей родительскую группу.
2. Если пользователь изменяет название группы, система сохраняет изменение.
3. Если пользователь при создании или изменении группы назначает родительскую группу, система проверяет связь: если родительской указана сама группа или одна из её дочерних групп, выполняется исключительный сценарий E2; иначе система сохраняет допустимую связь.
4. Если пользователь выбирает группу для просмотра, система показывает требования этой группы и всех её дочерних групп.
5. Если пользователь запрашивает удаление группы, система проверяет, содержит ли она требования или дочерние группы: если не содержит, выполняется альтернативный сценарий A1; если содержит, выполняется исключительный сценарий E1.

## Alternative flows

### A1 — Удаляемая группа не содержит требований и дочерних групп

1. Этот сценарий выполняется, если на шаге 5 основного сценария пользователь запросил удаление группы, не содержащей требований и дочерних групп.
2. Система удаляет группу.

## Exception flows

### E1 — Группа содержит требования или дочерние группы

1. Этот сценарий выполняется, если на шаге 5 основного сценария пользователь запросил удаление группы, содержащей требования или дочерние группы.
2. Система отклоняет запрос.

### E2 — В качестве родительской указана сама группа или одна из её дочерних групп

1. Этот сценарий выполняется, если на шаге 3 основного сценария пользователь назначил родительской саму группу или одну из её дочерних групп.
2. Система отклоняет изменение.

1. Пользователь пытается сделать группу дочерней самой себе или одной из своих дочерних групп.
2. Система отклоняет изменение и информирует пользователя о недопустимой связи.
