# UC-0002 — Просмотр списка требований проекта

## Цель

Просмотреть и найти требования выбранного проекта.

## Основной актор

Пользователь

## Триггер

Пользователь выбирает доступный ему проект, чтобы просмотреть его требования.

## Предварительные условия

- Пользователь аутентифицирован.
- Пользователю доступен хотя бы один проект.

## Основной поток

1. Пользователь выбирает проект, к которому у него есть доступ; если у пользователя нет права `read` в выбранном проекте, выполняется исключительный поток E1.
2. Система устанавливает выбранный проект активным и отображает доступные для чтения требования.
3. Если пользователь хочет уточнить список с помощью поиска, фильтрации или сортировки, выполняется альтернативный поток A1; если пользователь выбирает пункт «Все» в дереве групп, выполняется альтернативный поток A2; если пользователь изменяет ширину столбцов таблицы, выполняется альтернативный поток A3; если пользователь выбирает требование для просмотра, система открывает его карточку согласно [UC-0013](UC-0013.md).

## Альтернативные потоки

### A1 — Поиск, фильтрация или сортировка списка

1. Пользователь вводит поисковый текст для поиска по краткому и подробному описанию и/или выбирает одно или несколько значений фильтров по типу, важности, сложности, статусу и релизу.
2. При выборе нескольких значений одного фильтра система включает требования, соответствующие хотя бы одному из них; при одновременном применении поискового текста и фильтров система формирует список согласно [FR-0039](../functional/FR-0039.md).
3. Система сразу обновляет список после изменения поискового текста или фильтра; если пользователь одним действием сбрасывает параметры поиска и фильтрации, выполняется альтернативный поток A4.
4. Если пользователь выбирает сортировку столбца, система сортирует обновлённый список согласно [FR-0016](../functional/FR-0016.md); если пользователь выбирает требование для просмотра, система открывает его карточку согласно [UC-0013](UC-0013.md).

### A2 — Сброс отбора по группе

1. Пользователь выбирает пункт «Все» в дереве групп.
2. Система снимает отбор по группе и обновляет список требований активного проекта, сохраняя заданные поиск, остальные фильтры и сортировку.
3. Пользователь продолжает работу со списком; если он выбирает требование для просмотра, система открывает его карточку согласно [UC-0013](UC-0013.md).

### A3 — Изменение ширины столбцов таблицы

1. Пользователь изменяет ширину одного или нескольких столбцов списка требований.
2. Система сохраняет выбранную ширину столбцов для этого пользователя и продолжает отображение списка с учётом выбранных ширины столбцов.
3. Пользователь продолжает работу со списком; если он выбирает требование для просмотра, система открывает его карточку согласно [UC-0013](UC-0013.md).

### A4 — Сброс параметров поиска и фильтрации

1. Пользователь одним действием сбрасывает параметры поиска и фильтрации.
2. Система снимает поисковое условие и сбрасывает фильтры по полям, сразу обновляя список и сохраняя отбор по группе и сортировку.
3. Пользователь продолжает работу со списком; если он выбирает требование для просмотра, система открывает его карточку согласно [UC-0013](UC-0013.md).

## Исключительные потоки

### E1 — Нет права на просмотр требований проекта

1. Система не отображает требования проекта и сообщает об отсутствии права на чтение.

## Постусловия

- Пользователь просмотрел список требований выбранного проекта и, при необходимости, уточнил его параметры.
- Если пользователь изменил ширину столбцов, система сохранила её для этого пользователя между сеансами.
