# UC-0002 — Просмотр требований проекта

## Цель

Найти требование проекта и просмотреть его карточку и существующие связи.

## Основной актор

Пользователь

## Триггер

Пользователь выбирает доступный ему проект, чтобы просмотреть его требования.

## Предварительные условия

- Пользователь аутентифицирован.
- Пользователю доступен хотя бы один проект.
- Для просмотра требований пользователь имеет право `read` (чтение) в выбранном проекте.

## Основной сценарий

1. Пользователь выбирает проект, к которому у него есть доступ.
2. Система устанавливает выбранный проект активным и отображает доступные для чтения требования.
3. При необходимости пользователь находит нужные требования с помощью поиска, фильтрации или сортировки списка.
4. Пользователь открывает карточку требования.
5. Система отображает данные требования и его существующие связи, включая направление связей направленных типов.

## Альтернативные сценарии

### A1 — Поиск, фильтрация или сортировка списка

1. Этот сценарий выполняется, если пользователь хочет уточнить отображаемый список требований.
2. Пользователь задаёт параметры поиска, фильтрации или сортировки.
3. Система обновляет список в соответствии с выбранными параметрами.
4. Пользователь продолжает работу со списком или открывает карточку требования.

## Исключительные сценарии

### E1 — Нет права на просмотр требований проекта

1. Этот сценарий выполняется, если пользователь выбирает проект, к которому у него есть доступ, но не имеет права `read` в этом проекте.
2. Система не отображает требования проекта и сообщает об отсутствии права на чтение.
