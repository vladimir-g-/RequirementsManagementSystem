# UC-0002 — Просмотр списка требований проекта

## Цель

Просмотреть и найти требования выбранного проекта.

## Основной актор

Пользователь

## Триггер

Пользователь выбирает доступный ему проект, чтобы просмотреть его требования.

## Предварительные условия

- Пользователь аутентифицирован.
- Пользователю доступен хотя бы один проект.

## Основной сценарий

1. Пользователь выбирает проект, к которому у него есть доступ; если у пользователя нет права `read` в выбранном проекте, выполняется исключительный сценарий E1.
2. Система устанавливает выбранный проект активным и отображает доступные для чтения требования.
3. Если пользователь хочет уточнить список с помощью поиска, фильтрации или сортировки, выполняется альтернативный сценарий A1; если пользователь изменяет ширину столбцов, система сохраняет выбранную ширину для этого пользователя между сеансами; если пользователь выбирает требование для просмотра, система открывает его карточку согласно [UC-0013](UC-0013.md).

## Альтернативные сценарии

### A1 — Поиск, фильтрация или сортировка списка

1. Пользователь задаёт параметры поиска, фильтрации или сортировки.
2. Система обновляет список в соответствии с выбранными параметрами.
3. Пользователь продолжает работу со списком; если он выбирает требование для просмотра, система открывает его карточку согласно [UC-0013](UC-0013.md).

## Исключительные сценарии

### E1 — Нет права на просмотр требований проекта

1. Система не отображает требования проекта и сообщает об отсутствии права на чтение.

## Постусловия

- Пользователь просмотрел список требований выбранного проекта и, при необходимости, уточнил его параметры.
- Если пользователь изменил ширину столбцов, система сохранила её для этого пользователя между сеансами.
