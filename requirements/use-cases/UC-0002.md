# UC-0002 — Управление требованиями проекта

## Цель

Работать с требованиями проекта, к которому предоставлен доступ.

## Основной актор

Пользователь

## Предварительные условия

- Пользователь аутентифицирован.
- Пользователю доступен хотя бы один проект.

## Основной сценарий

1. Пользователь выбирает проект, к которому у него есть доступ.
2. Система показывает требования, доступные пользователю для чтения.
3. При необходимости пользователь ищет, фильтрует или сортирует отображаемые требования.
4. В соответствии со своими правами пользователь создаёт, изменяет или удаляет требование.
5. При создании требования система присваивает ему номер.
