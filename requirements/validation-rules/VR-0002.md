# VR-0002 — Допустимые справочные значения требования

## Условие валидации

При создании или изменении требования значения его полей «тип», «статус» и «важность» должны совпадать с одним из значений соответствующих системных справочников.

## Область применения

- Сущность: требование.
- Атрибуты: тип, статус, важность.
- Операции: создание требования, изменение требования; при фильтрации требований используются те же справочные значения.
