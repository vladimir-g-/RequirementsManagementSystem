# VR-0004 — Код проекта

## Условие валидации

Код проекта должен быть:

- непустым;
- соответствовать формату префикса номера требования, установленному в [VR-0001](VR-0001.md);
- уникальным без учёта регистра среди других проектов.

## Область применения

- Сущность: проект.
- Атрибут: код.
- Операции: создание проекта, изменение кода проекта; код может изменяться только пока проект не содержит ни требований, ни групп ([BRL-0011](../business-rules/BRL-0011.md)).
