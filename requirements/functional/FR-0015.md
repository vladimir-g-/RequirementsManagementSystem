# FR-0015 — Фильтрация требований

## Требование

Система должна позволять пользователю фильтровать видимые требования по типу, важности, сложности, статусу и релизу, в том числе выбирать несколько значений для одного фильтра. Если для одного фильтра выбрано несколько значений, система включает требования, соответствующие хотя бы одному из них. При одновременном применении разных фильтров результат должен соответствовать каждому из них. Изменение фильтра должно сразу обновлять список.
