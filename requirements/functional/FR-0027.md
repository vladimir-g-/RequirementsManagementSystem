# FR-0027 — Самостоятельная смена пароля

## Требование

Система должна позволять аутентифицированному пользователю изменить пароль своей учётной записи из формы профиля. После сохранения нового пароля система должна попытаться завершить каждый активный сеанс этой учётной записи; если завершить конкретный сеанс не удалось, он остаётся активным.
