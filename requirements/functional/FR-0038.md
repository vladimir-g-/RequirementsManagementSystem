# FR-0038 — Сброс параметров поиска и фильтрации

## Требование

Система должна позволять пользователю одним действием очистить поисковый текст и сбросить фильтры по полям. После сброса система обновляет список без этих ограничений, сохраняя отбор по группе и сортировку.
