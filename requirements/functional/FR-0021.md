# FR-0021 — Создание связи между требованиями

## Требование

Система должна позволять пользователю создавать связь с выбранным типом из каталога между двумя разными требованиями одного проекта. При создании связи с карточки существующего требования пользователь должен иметь права `read` (чтение) и `update` (изменение); требование, с карточки которого инициировано создание связи, является A, а выбранное требование — B. При создании нового требования пользователь должен иметь право `create` (создание), а для выбора существующих требований — право `read` (чтение); право `update` (изменение) для этого не требуется, новое требование является A, а выбранное существующее требование — B. Тип связи задаёт отношение A к B.
