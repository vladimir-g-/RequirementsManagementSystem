# FR-0021 — Создание связи между требованиями

## Требование

Система должна позволять пользователю, одновременно имеющему права `read` (чтение) и `update` (изменение) в активном проекте, на карточке требования найти другое требование того же проекта и создать между ними связь с выбранным типом из каталога. Для направленной связи система должна считать требованием A то требование, на карточке которого пользователь инициировал создание связи, а требованием B — выбранное им другое требование; тип связи задаёт отношение A к B.
