# FR-0035 — Изменение типа требования

## Требование

Система должна позволять администратору в форме управления списком типов требований изменять название любого типа требования, в том числе типа, который уже используется требованиями в проектах. Система должна проверять новое название в соответствии с [BRL-0014](../business-rules/BRL-0014.md) и при прохождении проверки сохранять название. Новое название должно применяться ко всем существующим требованиям данного типа. Изменение названия типа требования не должно изменять нумерацию требований: нумерация определяется префиксами для пар «проект — тип» согласно [BRL-0004](../business-rules/BRL-0004.md), и настройки префиксов при изменении названия типа сохраняются.
