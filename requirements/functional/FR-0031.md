# FR-0031 — Изменение кода проекта

## Требование

Система должна позволять администратору изменять код проекта только если проект не содержит ни требований, ни групп. Система должна проверять новый код в соответствии с [VR-0004](../validation-rules/VR-0004.md) и при прохождении проверки сохранять код.
