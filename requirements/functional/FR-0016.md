# FR-0016 — Сортировка требований

## Требование

Система должна позволять пользователю сортировать требования активного проекта по номеру, описанию, типу, важности, сложности, статусу и релизу, циклически переключая для выбранного столбца сортировку по возрастанию, по убыванию и без сортировки.
