# FR-0024 — Удаление связи между требованиями

## Требование

Система должна позволять пользователю с правом `update` (изменение) в проекте удалить существующую связь между требованиями с карточки любого из связанных требований, не удаляя сами требования. Создание и удаление связи трактуются как изменение требования, поэтому отдельное право `read` для этой операции не требуется; право `read` нужно только для открытия карточки требования.
