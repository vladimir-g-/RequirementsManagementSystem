# FR-0024 — Удаление связи между требованиями

## Требование

Система должна позволять пользователю, одновременно имеющему права `read` (чтение) и `update` (изменение) в проекте, удалить существующую связь между требованиями с карточки любого из связанных требований, не удаляя сами требования.
