# FR-0006 — Создание требования

## Требование

Система должна позволять пользователю с правом `create` (создание) в активном проекте создавать требование, указывая краткое описание, тип, важность и статус, а также при необходимости подробное описание, сложность, релиз и группу. При открытии формы создания нового требования система должна отображать пустую таблицу связанных требований. Пользователь с правом `read` (чтение) в активном проекте может указать в форме одно или несколько существующих требований этого проекта и выбрать тип связи для каждого; для этого не требуется право `update` (изменение). При сохранении система должна сохранять новое требование и все указанные связи как одну операцию; для направленной связи новое требование является A, а выбранное существующее требование — B.
