# FR-0032 — Удаление пустого проекта

## Требование

Система должна позволять администратору удалять проект только если он не содержит ни требований, ни групп согласно [BRL-0012](../business-rules/BRL-0012.md), и при удалении удалять из учётных записей пользователей доступ к этому проекту и права доступа к нему, а также настройки префиксов номеров требований для этого проекта. Если удалённый проект был активным, после удаления система должна отображать состояние без активного проекта до явного выбора проекта пользователем; требования и группы при этом не отображаются.
