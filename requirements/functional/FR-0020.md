# FR-0020 — Управление каталогом типов связей

## Требование

Система должна предоставлять отдельную форму для управления единым каталогом типов связей, используемым во всех проектах, только пользователю с системной ролью «Администратор». Пользователь без этой роли не должен иметь возможности открыть форму или просматривать каталог. Администратор должен иметь возможность создавать типы связей, изменять их названия и направленность, а также удалять их. Изменение направленности должно применяться ко всем существующим связям данного типа; удаление типа должно удалять все связи этого типа во всех проектах, не удаляя связанные требования.

При первоначальной настройке каталог должен содержать следующие типы:

| Тип | Направленность | Значение |
|---|---|---|
| Уточняет | Направленная | A уточняет B |
| Основано на | Направленная | A основано на B |
| Зависит от | Направленная | A зависит от B |
| Конфликтует с | Симметричная | Требования конфликтуют друг с другом |
| Дублирует | Симметричная | Требования дублируют друг друга |
| Связано с | Симметричная | Требования связаны, но более конкретный тип не выбран |
