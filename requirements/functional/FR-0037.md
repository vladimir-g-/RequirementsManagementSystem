# FR-0037 — Предоставление типов требований при работе с требованиями

## Требование

Система должна предоставлять любому аутентифицированному пользователю список всех типов требований для выбора типа при создании и изменении требования и для фильтрации требований по типу. Предоставление этого списка не должно открывать доступ к форме управления типами требований и не должно позволять создавать, изменять или удалять типы требований.
