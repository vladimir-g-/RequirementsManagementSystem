# FR-0023 — Доступ к меню «Администрирование»

## Требование

Система должна отображать меню «Администрирование» и предоставлять доступ ко всем его пунктам только пользователю с системной ролью «Администратор». Пользователь без этой роли не должен видеть меню или иметь возможность открыть административные функции.
