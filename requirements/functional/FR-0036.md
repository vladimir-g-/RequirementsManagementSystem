# FR-0036 — Удаление неиспользуемого типа требования

## Требование

Система должна позволять администратору в форме управления списком типов требований удалять тип требования. Удаление должно быть возможным только если тип не используется ни одним требованием ни в одном проекте согласно [BRL-0013](../business-rules/BRL-0013.md); в противном случае система должна отклонять удаление и сообщать об этом.
