# AC-0004 — Изменение требования

## Связанный артефакт

- [FR-0007](../functional/FR-0007.md)

## Правила валидации

- [VR-0002](../validation-rules/VR-0002.md)

## Критерии

| # | Дано | Когда | Тогда |
|---|---|---|---|
| 1 | Пользователь имеет право `update` (изменение) для требования. | Пользователь изменяет доступное для редактирования поле и сохраняет требование. | Изменённое поле сохраняется, а номер требования остаётся прежним. |
| 2 | Пользователь имеет право `update` (изменение) для требования. | Система получает запрос на изменение, в котором тип, статус или важность не входят в соответствующие системные справочники (нарушение [VR-0002](../validation-rules/VR-0002.md)). | Система отклоняет изменение; исходные данные требования сохраняются без изменений. |
| 3 | Пользователь имеет право `update` (изменение) для требования; в форме изменения введены новые значения полей, но изменение ещё не сохранено. | Пользователь отменяет изменение до сохранения. | Система прекращает редактирование, не сохраняет введённые значения и отображает данные требования в состоянии до начала редактирования. |
| 4 | Пользователь имеет право `read` (чтение), но не имеет права `update` (изменение) для проекта. | Пользователь пытается изменить требование доступными в интерфейсе способами. | Система не предоставляет возможности изменения. |
| 5 | Пользователь не имеет права `update` (изменение) для проекта. | Система получает запрос на изменение требования в обход интерфейса. | Система отклоняет запрос; данные требования остаются без изменений. |
