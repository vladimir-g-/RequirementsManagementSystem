# AC-0004 — Изменение требования

## Связанный артефакт

- [FR-0007](../functional/FR-0007.md)

## Критерии

### Дано

Пользователь имеет право `update` (изменение) для требования.

### Когда

Пользователь изменяет доступное для редактирования поле и сохраняет требование.

### Тогда

Изменённое поле сохраняется, а номер требования остаётся прежним.
