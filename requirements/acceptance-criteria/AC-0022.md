# AC-0022 — Доступность типов требований при работе с требованиями

## Связанные артефакты

- [FR-0037](../functional/FR-0037.md)

## Критерии

| # | Дано | Когда | Тогда |
|---|---|---|---|
| 1 | Пользователь аутентифицирован, имеет право `create` в проекте и системную роль «Пользователь» или «Администратор»; в справочнике есть несколько типов требований. | Пользователь открывает форму создания требования. | Система отображает в поле «Тип» все типы требований из справочника. |
| 2 | Пользователь аутентифицирован, имеет право `update` в проекте и системную роль «Пользователь» или «Администратор»; в справочнике есть несколько типов требований. | Пользователь открывает форму изменения требования. | Система отображает в поле «Тип» все типы требований из справочника, включая текущий тип требования. |
| 3 | Пользователь аутентифицирован, имеет право `read` в проекте и системную роль «Пользователь» или «Администратор»; в справочнике есть несколько типов требований. | Пользователь открывает фильтр требований по типу. | Система отображает в фильтре все типы требований из справочника. |
| 4 | Администратор создал новый тип требования. | Пользователь аутентифицирован, имеет право `create` или `update` в проекте и системную роль «Пользователь» или «Администратор»; пользователь открывает форму создания или изменения требования. | Новый тип требования доступен для выбора в поле «Тип». |
