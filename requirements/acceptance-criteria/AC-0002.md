# AC-0002 — Ограничения доступа к проектам

## Критерии

| # | Дано | Когда | Тогда |
|---|---|---|---|
| 1 | Пользователь имеет роль администратора; в системе существуют проекты, к которым он не назначен. | Пользователь открывает список проектов. | Система показывает все проекты системы, включая те, к которым пользователь не назначен. |
| 2 | Пользователь без роли администратора назначен только в проект A; в системе существует проект B, к которому он не назначен. | Пользователь открывает список проектов. | Система показывает только проект A; проект B в списке отсутствует. |
| 3 | Пользователь без роли администратора имеет доступ к проекту A, но не имеет в нём права `read` (чтение); проект A отображается в списке проектов. | Пользователь выбирает проект A в списке проектов. | Система не отображает требования проекта A и сообщает об отсутствии права на чтение. |
| 4 | Пользователь имеет право `read` (чтение) в проектах A и B; активный проект не выбран. | Пользователь выбирает проект A в списке проектов. | Система устанавливает проект A активным и отображает требования только проекта A; требования проекта B не отображаются. |
| 5 | Проект A активен; пользователь имеет право `read` (чтение) в проектах A и B. | Пользователь выбирает в списке проектов проект B. | Система устанавливает проект B активным и отображает требования только проекта B; требования проекта A из списка исчезают. |
| 6 | Проект активен; пользователь имеет в нём право `read` (чтение); в проекте есть требование с заполненными номером, кратким описанием, группой, типом, важностью, сложностью, статусом и релизом. | Пользователь открывает список требований активного проекта. | Система отображает для требования все перечисленные значения: номер, краткое описание, группу, тип, важность, сложность, статус и релиз. |
