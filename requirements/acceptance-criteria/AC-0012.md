# AC-0012 — Выход из системы

## Связанный артефакт

- [FR-0002](../functional/FR-0002.md)

## Критерии

### Дано

Пользователь аутентифицирован.

### Когда

Пользователь выходит из системы, а затем пытается обратиться к защищённой функции.

### Тогда

Система больше не считает пользователя аутентифицированным и не предоставляет ему доступ к защищённым функциям.
