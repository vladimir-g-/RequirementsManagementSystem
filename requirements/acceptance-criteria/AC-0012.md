# AC-0012 — Выход из системы

## Связанный артефакт

- [FR-0002](../functional/FR-0002.md)

## Критерии

| # | Дано | Когда | Тогда |
|---|---|---|---|
| 1 | Пользователь аутентифицирован, сеанс активен. | Пользователь выбирает команду выхода из системы. | Система завершает сеанс и отображает страницу входа. |
| 2 | Пользователь только что вышел из системы. | Пользователь вводит в адресной строке браузера адрес страницы приложения, например страницы требований, и открывает его. | Система не отображает запрошенную страницу, а показывает страницу входа. |
| 3 | Пользователь аутентифицирован, но сеанс уже неактивен. | Пользователь выбирает команду выхода из системы. | Система считает сеанс завершённым и отображает страницу входа; сообщение об ошибке не показывается. |
| 4 | Пользователь аутентифицирован, сеанс активен, и система не может завершить сеанс. | Пользователь выбирает команду выхода из системы. | Система отображает сообщение о том, что завершить сеанс не удалось; сеанс остаётся активным, а текущее состояние интерфейса сохраняется. |
