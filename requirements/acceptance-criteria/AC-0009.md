# AC-0009 — Удаление требования

## Связанный артефакт

- [FR-0008](../functional/FR-0008.md)

## Критерии

| # | Дано | Когда | Тогда |
|---|---|---|---|
| 1 | Пользователь имеет право `delete` (удаление) для требования, у которого есть связи с двумя другими требованиями. | Пользователь подтверждает удаление. | Система удаляет требование и все его связи; оба связанных требования остаются в проекте со своими данными. |
| 2 | Пользователь имеет право `delete` (удаление) для требования. | Пользователь инициирует удаление и отменяет подтверждение. | Система не удаляет требование и его связи. |
| 3 | Пользователь не имеет права `delete` (удаление) для проекта. | Пользователь пытается удалить требование доступными в интерфейсе способами. | Система не предоставляет возможности удаления. |
| 4 | Пользователь не имеет права `delete` (удаление) для проекта. | Система получает запрос на удаление требования в обход интерфейса. | Система отклоняет запрос; требование и его связи остаются без изменений. |
