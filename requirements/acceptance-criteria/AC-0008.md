# AC-0008 — Проверка префикса

## Связанный артефакт

- [FR-0018](../functional/FR-0018.md)

## Критерии

| # | Дано | Когда | Тогда |
|---|---|---|---|
| 1 | Администратор настраивает префикс для проекта и типа требования. | Администратор указывает непустой префикс длиной не более 20 символов, состоящий только из букв, цифр, `_` или `-` и ещё не использованный для этой пары «проект — тип». | Система сохраняет префикс для этой пары. |
| 2 | Администратор настраивает префикс для проекта и типа требования. | Администратор указывает пустой или слишком длинный префикс, префикс с недопустимыми символами либо дубликат для этой пары. | Система отклоняет префикс. |
