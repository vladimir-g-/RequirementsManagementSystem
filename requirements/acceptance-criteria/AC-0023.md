# AC-0023 — Фильтрация требований

## Связанный артефакт

- [FR-0015](../functional/FR-0015.md)

## Критерии

| # | Дано | Когда | Тогда |
|---|---|---|---|
| 1 | Пользователь имеет право просматривать требования активного проекта. | Пользователь применяет один или несколько доступных фильтров, включая фильтр по типу. | Отображаемые требования соответствуют активным фильтрам. |
| 2 | Для одного фильтра доступны несколько значений. | Пользователь выбирает несколько значений этого фильтра. | Система включает требования, соответствующие хотя бы одному выбранному значению. |
| 3 | Пользователь задаёт условия в нескольких разных фильтрах. | Пользователь изменяет значение любого из них. | Список сразу обновляется и содержит только требования, соответствующие каждому активному фильтру. |
